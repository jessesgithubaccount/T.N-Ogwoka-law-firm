# T.N.Ogwoka & Osili Advocates (Next.js)

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

Routes: `/`, `/about`, `/team`, `/practice-areas`, `/privacy-policy`, `/terms-of-service`, `/contact`.
Styles are in `app/globals.css`, images in `public/images`, shared pieces in `components/`.
